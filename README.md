# まいにち英単語

中学英単語を「1日5語、例文と音声で」覚えるスマートフォン向けの学習アプリです。
ふつうの Web ページとして動き、iPhone の「ホーム画面に追加」でアプリのように使えます（PWA）。

- サーバーもログインもなし。学習記録は端末の中だけに保存されます
- 費用ゼロ。音声はブラウザ内蔵の読み上げ機能を使います
- 単語データは独自作成です（市販の単語帳の転載ではありません）

## 使い方（学習する人向け）

1. 公開 URL を iPhone の Safari で開く
2. 共有ボタン（四角から矢印のマーク）→「ホーム画面に追加」
3. ホーム画面の「英単語」から開く
4. 「はじめる」→ 1語ずつ「つぎへ」→ 最後に確認クイズ。毎日5分

- 知っている単語は「もう知ってる」で外せます（単語一覧の「さくさく仕分け」でまとめても可）
- まちがえた単語は翌日また出ます。覚えるほど間隔が空いていきます
- 機種変更のときは「設定 → 学習記録を書き出す」でファイルを保存し、新しい端末で「読み込む」

## 手元で動かす（Windows）

`run.bat` をダブルクリックすると、ポートを確認してからブラウザーが自動で開きます（終了は Ctrl+C）。
Python 3 が必要です。公開版はサーバー不要なので、これは確認用です。

## フォルダー構成

```
app/                公開されるファイル一式（これだけで動く）
  index.html        画面の入れ物
  css/style.css     見た目
  js/               動き（app.js が起点。views/ に画面ごとのファイル）
  data/words.json   単語データ（1語1行）
  sw.js             オフライン対応（更新時は VERSION を変える）
  manifest.webmanifest, icons/   ホーム画面用
tools/
  check_words.py    単語データの点検
  make_icons.py     アイコン画像の生成（Pillow が必要）
  serve.py          手元確認用の簡易サーバー
.github/workflows/pages.yml   GitHub Pages への自動公開
docs/               企画・設計・判断の記録（このリポジトリには含めていません）
```

## 単語を追加・修正する

1. `app/data/words.json` の `words` に1行追加（既存の行をコピーして書きかえる）

```json
{"id":"like","word":"like","pos":"動詞","meanings":["〜が好きだ"],"kana":"ライク","level":1,"theme":"気持ち","example":"I like music.","exampleJa":"私は音楽が好きです。"}
```

   - `id`: 小文字・重複なし　`level`: 1〜3（中1〜中3の目安）　`theme`: ファイル冒頭の `themes` のどれか
   - 例文の中で形が変わる語（likes, went など）は `"form":"likes"` を足す
   - 補足があれば `"note":"…"`
   - 並び順 = 学習する順番

2. 点検する

```bash
python tools/check_words.py
```

3. `app/sw.js` の `VERSION` を変える（端末に残った古いデータを入れ替えるため）
4. `main` に push すると GitHub Pages が自動で更新されます（数分）

## 公開のしくみ

`main` ブランチに push すると、`.github/workflows/pages.yml` が `app/` フォルダーを GitHub Pages に配信します。
リポジトリの Settings → Pages で Source が「GitHub Actions」になっている必要があります。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 音が出ない | 端末の音量、マナーモード。設定の「音声テスト」。iPhone は初回だけ画面を一度タップしてから鳴ることがあります |
| 更新したのに画面が変わらない | `sw.js` の VERSION を変えたか。アプリを一度閉じて開き直す |
| 学習記録が消えた | Safari で「ホーム画面に追加」せずに使っていると、しばらく開かないときに消えることがあります。追加して使い、たまに「書き出す」で保存を |
| 単語データの誤り | `words.json` を直して点検 → push |

## 技術メモ（保守する人向け）

- 画面は `js/app.js` の `go('画面名')` で切り替え。各画面は `js/views/*.js` の `render(ctx)` が要素を返す
- 学習記録の形は `js/store.js`、復習の間隔は `js/srs.js`（箱0〜5、日数 1/1/3/7/14/30）
- 「今日の単語」の選び方・クイズ問題づくりは `js/session.js`
- 外部ライブラリなし。Google Fonts（M PLUS Rounded 1c）だけ読み込み、なければ端末のフォントで表示
